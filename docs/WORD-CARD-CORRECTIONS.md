# 词卡修正 · 1.4.1

本轮补齐内置音标显示、修正暗色释义对比度，并加入个人释义编辑。不增加账号、服务器或付费接口。

## 如何编辑

1. 展开词卡释义，点击释义行最右侧的灰色铅笔。
2. 修改中文内容后点击“保存”（也可 Ctrl/Command + Enter）；取消或 Escape 不保存。
3. 该词在主题词库、搜索、每日任务、历史词单、每日/每周复习与自测中统一显示最新个人释义。未修改的词继续显示当前版本的默认释义。
4. 展开“个人释义 · 查看默认版本”可以查看原文，并点击“恢复默认释义”。恢复后使用公共词库的最新默认版本。

这里的同步指**同一浏览器内的各个学习入口共用一份个人词库**。不会改动其他人的默认词库，不会把个人修改上传 GitHub；跨设备仍通过完整备份迁移。完整备份包含个人释义；词库 JSON/CSV 导出也显示当前有效释义，但迁移个人修改和重置记录应使用“完整备份”。

## 数据兼容

沿用 IndexedDB 版本 2、AppState 版本 1。新增可选 `wordEdits[wordId] = {meaning?, updated}`。原词条、ID、学习状态、任务、完成记录和自测答案都不被编辑操作改写。

应用统一词库时，以个人记录覆盖对应 ID 的释义；不存在覆盖记录时采用原内容。重置保存带时间的空覆盖记录，防止导入较旧备份时把已经取消的修改复活。备份合并按每个词的操作时间取较新记录，旧备份缺少该字段仍可恢复。

## 音标与颜色

767 条内置词均有音标或逐词音标；原英式资料优先，其余采用明确标记的美式资料。来源、许可及补充项范围见 [音标说明](../content/vocabulary/PHONETICS.md)。短语的逐词音标不等于整句连读。系统朗读与辞书真人录音不同。

暗色释义为 `#fff`，编辑图标低对比度、无大按钮边框，位于释义行右边；手机和桌面采用同一保存逻辑。

## 验证

- 56 项测试通过，覆盖旧备份兼容、个人编辑及恢复、较新覆盖合并、原词库不变、已有进度不变和音标标签。
- 在隔离端口实测：修改 gradual、刷新后保留、词库及每日任务同步、自测题干采用修改后的释义、恢复默认和取消编辑。
- 浏览器实际计算暗色释义为 `rgb(255,255,255)`；编辑图标右侧与释义行右侧相差 0 像素；手机内容宽与页面宽均为 375 像素，无整页横向溢出。
- 本轮测试没有读取或修改在线站点的真实学习记录。
