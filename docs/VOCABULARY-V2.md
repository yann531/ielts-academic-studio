查阅日期 2026-11-16。部分 Cambridge 页面直接访问返回 403，相关页面可通过搜索索引核查；全库的词典链接是**供学习者核查的检索入口**，没有宣称逐页访问并核验 767 条。音标只收录本次较有把握的 38 条，其余不填占位符。词形资料也未伪装为全库覆盖。全库尚无真人辞书编辑或雅思教师逐条终审，例句不是官方真题，词库不是官方指定表。

## 页面与实际流程

- **每日词汇**：从未学、未归档、未被派发的词中按主题交错选择，优先补足近七天较少安排的主题；先接续未完成的任务，再补足当日上限。当天列表、顺序、上限生成后保存，刷新、重复学习或临时改设置均不重抽。设置的新数量从下一次生成词单起生效。
- **每日任务**：直接进入同一份词单与自测，不再另建背词队列。完成后按钮变为“再次学习 / 自测”，仍能进入。听读写说、复盘原有流程保留。
- **历史列表**：按学习日查看原新词、复习词、完成情况和自测轮次。顺延保留原日期；卡片显示实际完成新词日期。历史列表保留原分配，当前人工状态另行显示。过去日期只浏览和自测，不回写过去的学习完成。
- **每日复习**：纳入此前三天的新学词、到期词、未完成复习、再练和易忘。当天新词已经出现的词不重复放入复习。不同来源合并为一个词，显示来源标签；已完成列表仍可反复看。
- **每周复习**：本周新词、到期 OK、再练、易忘分别显示数量，去重后集中复习。集中复习的完成同步当天记录；来源与完成保留。
- **易忘列表 / 已斩归档**：独立入口，可以集中看卡、自测。斩词可恢复到再练，旧版“掌握/暂停”也迁到可恢复归档，不删除原卡片。
- **主题词库**：按主题、英文或中文搜索，保留个人添加、JSON/CSV 导出和个人资料架导入。自由浏览不另外派发新词；标记会即时保存。

### 人工状态和复习规则

| 操作 | 后续行为 |
| --- | --- |
| 再练 | 每天出现，答对、自测或复习完成都不会自动移除 |
| OK | 参加到期周期及周复习，不成为永久每日必练 |
| 斩 | 从日常队列移出，保留历史、自测与备份，可恢复 |
| 易忘 | 独立开关，每日/每周集中复习；不覆盖再练/OK；归档期间隐藏但保留标记 |

初学后的前三天安排复习；之后依据已完成复习次数使用约 7 / 14 / 30 天间隔。标记 OK 时先安排次日复习，之后跟随周期；再练与易忘的每日规则优先。没有保留原“最多 30 词”的硬截断，否则无法保证所有再练词每天出现。新词的每日上限继续由计划设置控制。

用户主动选择再练/OK/斩表示已处理这张新词卡，会记入该词任务的完成日期；单纯展开答案、朗读或自测均不会自动完成新词任务或判断掌握。每天同一词的“完成学习”只记一次，仍允许不限次数浏览和自测。

网站关闭期间不在后台派发新词；下次打开时接续最早未完成的任务，按当天容量安排，不给未打开的日期虚构一批新词。主练习与复盘仍按原课程规则顺延。

### 自测

英文回忆释义采用学习者核对后自评；中文释义输入英文采用确定的拼写判分。忽略大小写、全角/半角和多余空格，只额外接受词条明确列出的拼写变体，不擅自接受复数、漏词或少连字符。输入和揭晓状态保存；拼写判分即记录答案和错误。每轮可继续或重新随机开始，旧轮次不清空。历史显示原输入、结果、完整答案与词条内容；实际时间以自测的开始时间记录。

## 数据、迁移与备份

AppState 继续使用 `version: 1`；IndexedDB 继续版本 2，`state/main` 和 `content/bank` 不换名称。新增可选 `vocabulary`：

- `progress`：人工状态与操作时间、独立易忘标记、初学/复习/到期日及复习次数。
- `tasks[wordId]`：唯一的新词任务及原始日期、实际完成日。同词顺延仍是同一个任务。
- `days[date]`：固定新词/复习 ID、完成 ID、来源与生成时的容量；`excludedIds` 仅表示旧任务对应内容已停止派发而免学，不计为初学或掌握。
- `tests`：稳定轮次 ID、随机顺序、答案、错误、输入草稿、揭晓与结束状态。
- `events`：状态变更的时间记录。

旧 `cards`、`reviews`、每日课程 notes 和其他记录保留，学习完成时兼容更新旧字段。原词条的平面字段也保留，新增 `collocations`、`examples`、`forms`、`tags`、`sources`、`retired` 等均为可选；旧个人词库继续导入。

第一次读取旧状态时，先在同一 IndexedDB 保存 `state/before-vocabulary-v1` 自动快照，再运行幂等迁移。设置中可导出“背词升级前快照”。无法验证的旧数据不自动重置。正常导出完整备份包含全部新状态、词单、自测、个人词库、旧记录与资料。

备份恢复先校验、预览，再按 ID 合并：人工状态与易忘开关分别取操作时间较新者；保留双方词单、完成与测试记录；重复导入不重复生成。若两台设备已为同一天生成不同词单，合并取并集，可能超过原上限，以保存双方真实历史。后续新词不会重复派发这些 ID。内置词库本身随代码版本提供，个人词条随完整备份提供。

旧内容缓存不得覆盖新版词库；内容包增加结构版本与词汇修订号检查。以后每一批词汇修订需同步提高 `vocabularyRevision`。未来词库更新不改学习 ID，不覆盖个人记录。

## 本地手动检查

1. 在原网址“设置与备份”导出完整备份。不要清理站点数据，不要为了测试换浏览器后误认为记录丢失。
2. 在 `D:\english` 启动网站（现有 `启动网站.cmd` 或 `node .tools/pnpm10/package/bin/pnpm.cjs dev`），打开“单词与短语 → 每日词汇”。记住当天几个词和顺序，刷新检查不变；更改新词上限后检查今天仍不变。
3. 展开卡片：查看词性、释义、搭配中文、完整例句译文、具体辨析、可用的词形和来源。
4. 把几个词分别标为再练、OK、斩；给 OK 或再练词加/去掉易忘，确认原状态不变。到已斩归档恢复，检查历史仍在。
5. 完成当天新词，从“每日任务”点击“再次学习 / 自测”，确认原列表仍可进入；试做拼写正确和错误各一题，判分后刷新、切回拼写模式，检查同题与结果恢复。
6. 完成一轮自测，再随机开始，展开记录检查旧轮次和原错误仍在。自测正确不应把再练变成 OK 或斩。
7. 查看历史与周复习；次日打开检查未完成词优先接续、再练每天出现、同词不重复。历史显示原任务和实际完成日期。
8. 导出备份，预览并合并恢复同一备份两次，检查词单、归档、易忘、自测轮次没有重复；升级前快照可另行下载。
9. 切换黑色/浅色模式，缩小窗口到手机宽度，检查入口、词卡、拼写输入和完成按钮均可见，没有整页横向溢出。

开发者重建词库：编辑 `content/vocabulary/` 的分批 TSV，运行 `python -X utf8 scripts/curate-vocabulary.py`，再运行 `pnpm test`、`pnpm check:content`、`pnpm build`。`legacy-base.json` 是保留旧 ID 的原始基线，不能当作现行词库发给页面。完整重建 `scripts/rebuild-content.py` 已将质量整理作为最后一道词库工序。前后统计见 `reports/vocabulary-before.json` 与 `reports/vocabulary-after.json`。

## 验证范围

自动测试覆盖主题交错、同日固定、顺延去重、前三天和周期复习、未完成复习、归档恢复、独立易忘、重复自测、拼写变体、旧备份兼容及合并。浏览器用隔离端口的合成旧记录实测迁移、快照导出、完整备份、旧备份恢复、完成后重进、错误/正确判分、刷新恢复、重复自测和手机/桌面黑色模式。迁移前后合成作文、录音、资料与笔记逐项一致。没有清理、覆盖或操作在线站点中的真实学习记录。

已知边界：没有真人终审和全词库音标覆盖；没有自动口语/词汇语义评分；英文释义回忆由用户核对自评。官方词典外链和在线资源需联网，本地学习、排课、自测、状态与备份无需联网。
