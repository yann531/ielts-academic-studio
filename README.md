# IELTS Academic Studio

面向中文母语自学者的免费 IELTS Academic 学习空间。React + TypeScript + Vite，静态托管，无账号、数据库服务器或付费 API 的必要依赖。界面借鉴 iOS 的通透层次与柔和动效，兼顾长文阅读、移动背词、深浅主题与减少动态效果偏好。
https://yann531.github.io/ielts-academic-studio/

## 能实际做什么

- 资源中心：26 个原始来源入口，按听、读、写、说、词汇、语法、规则分类，配中文学习路线；包括官方样题、评分 PDF、系统课、出版社书籍和词典。
- 阅读：4 套原创精读套练，12 篇、160 题；分栏、独立滚动、高亮、笔记、收词、题号导航、限时、恢复、交卷解析及错题记录。
- 听力：3 套原创合成音教学套练，12 段 WAV、120 题；播放/暂停、速度、复听、全文、听写、限定播放的套练模式、答题与音频进度恢复。
- 写作：40 题（Task 1 / 2 各 20），数据图、地图、流程、审题与提纲；5 篇完整教学示例；计时、字数、自动保存、历史稿、重写比较、自评、复制批改提示词和导入反馈。
- 口语：20 组关联 Part 1–3 主题；逐题/约 11 分钟固定流程、准备和作答倒计时、朗读问题、麦克风录音、导入、回放、导出、素材与文字稿笔记。模型可选生成文字追问。
- 词汇：700 条词汇/短语、13 个主题，配义项、搭配、原创例句、语域与易错提醒；五种回忆练习、简化 SM-2、每日新词上限、已掌握/暂停、CSV/JSON 导入导出。
- 本机 IndexedDB、单标签页写入保护、完整 JSON 备份预览/合并/去重、私人 PDF/音频/笔记资料架、按需离线包。

## 先了解内容边界

**这是可以练习的学习工具，不是经过试题测量校准的模考平台。** 内置题目由 AI 辅助编写并作结构与答案一致性检查，没有真人雅思教师/考官终审。阅读篇幅精简；听力为 Microsoft Zira 单一合成声线，时长短于正式考试、题型以填空为主。不会标作官方真题，也不会把正确率放大成 IELTS band。写作示例不标分。

正式题型、真人音频、难度校准请结合资源中心的官方公开样题、IELTSx 和自己购买的 Cambridge Academic 卷。外部网站不属于本项目的离线内容。详见 [内容审计](public/CONTENT-AUDIT.md)。

写作/口语免费模式为自评、量表、批改提示词、外部反馈导入。**没有内置自动转写、真人批改或发音打分。** 可选服务仅分析所发送的文字，口语文字稿不输出发音或完整口语分。在线服务可能收费，默认关闭；地址、模型与密钥只在当前页面内存，刷新清除。

## 本地运行

安装 Node.js 22+ 和 pnpm 10.15.1 后，在项目目录执行：

```sh
pnpm install --frozen-lockfile
pnpm dev
```

打开终端显示的 `http://127.0.0.1:5173/`。不要双击 `index.html` 使用 file:// 协议；录音、存储与模块加载需要 localhost 或 HTTPS。

```sh
pnpm test
pnpm check:content
pnpm build
pnpm preview
```

`dist/` 为完整静态构建。`base: './'` 与 hash 路由支持 GitHub Pages 仓库子路径。生产构建结束生成可选 `sw.js` 离线包；用户在设置中选择下载，首次约需 46 MB 音频加页面资源。音频 Range 请求也可从缓存读取。

## GitHub Pages 零成本发布

1. 将代码推送到自己的公开仓库 `main`。
2. 在仓库 Settings → Pages → Source 选择 **GitHub Actions**。
3. `.github/workflows/pages.yml` 在通过测试、内容检查和构建后自动部署。仓库与 Pages 须符合 GitHub 当期免费额度和使用条款。
4. `.github/workflows/links.yml` 每月检查一次资源链接，产物保留 14 天；403/429/网络失败需人工复查，不直接判失效。GitHub 可能暂停长期无活动仓库的定时任务；可手动运行。

静态核心无服务器费、无 API 费。个人模型服务、域名、外部教材或第三方付费课均不包含在“免费核心”中。网址变化后，请在原网址先备份，再到新网址导入。

## 私人资料与备份

学习记录、草稿、录音、个人文件保存在当前浏览器的网站存储，不会自动落到 D 盘。请用设置 → 导出完整备份，手动保存到 `D:\english\private\`。该目录已加入 `.gitignore`。清理浏览器站点数据、使用隐私窗口、切换设备或域名都可能使旧记录不可见。

完整备份含个人材料；不要放入公开仓库、issues 或 GitHub Releases。合并恢复先验证结构，按 ID 去重；草稿与词卡按更新时间选取，当前未结束练习优先保留本机版本。建议合并前导出当前备份。单资料 ≤25 MB、单录音 ≤40 MB、备份导入 ≤150 MB；超大书籍保留在本地文件夹，用系统阅读器管理。

只有一个标签页可写入，其他标签页只读；关闭主标签后刷新即可接手。保存失败时立即导出备份。数据校验失败不会自动重置旧数据库。

## 增加内容

直接修改 `src/data/*.json`，按 [贡献与格式](docs/CONTENT.md) 完成来源、解析和人工复查，再运行检查。`scripts/seed-*.py` 是首批内容的可重建来源，重新运行会覆盖对应内置 JSON，请先保存手工修订。默认发布已检查的教学材料；未人工审阅的新增生成内容不应直接加入主题库。

所有外链、原始出处、内容不足和候选开源项目考察记录见 [研究记录](docs/RESEARCH.md)。这是原创实现，没有复制候选仓库的源码或题库。

## 每周计划与内容更新（v1.1）

首次打开自动生成本周及下周七日安排，包含每日到期复习、新词上限、具体单篇听读、写作与口语任务。按近期听读正确率选择强化科目；任务完成需手动确认。可重排和导出计划，关闭网站时不在电脑后台运行。

每七天联网检查同站内容清单，以 SHA-256 校验公共内容包后缓存在 IndexedDB，学习记录另库存储。更新不修改个人草稿、卡片和作答。每周日北京时间约 20:00，GitHub Actions 从 `content-reserve/` 发布一批原创练习并重新部署。已备 **4 批、共 24 道阅读专项题**，不计入当前 280 题；预备包耗尽后需继续编写并检查新包。GitHub 定时任务可能延迟，长期无活动仓库可能被暂停，可手动运行。

词书按主题显示已学和到期数量，五种回忆模式共用复习进度，词库每次显示 24 条。阅读/听力支持搜索和单篇练习；整套与单篇成绩按实际题数保存。

新增内容为 AI 辅助原创教学材料，含虚构研究与场景。参考 Anki 的主动回忆与到期优先、Quizlet 的多种回忆方式，自行实现简化 SM-2；没有复用其商业课程或算法服务。

## 每日课程与顺延（v1.2）

首页“进入今日学习”和周计划的日期入口直接打开当天课程：具体新词卡、到期复习、指定单篇听读或写说任务、复盘笔记。全程留在每日课程页；题库保留用于自由练习。

每日默认最多 15 个新表达（设置可改）、30 个到期复习、1 项听读写说主练习、1 次复盘。新词按词条逐个保存，未完成部分先补齐每日量，再安排新内容。例如周一 15 个词学完 5 个，周二先学剩余 10 个，再接 5 个后续词；周一阅读没交卷，周二继续原题，原定周二主练习后移。连续漏学、跨周时也保持容量，不把所有欠账一次性加上。复习词按实际到期时间优先选取，最多 30 个，剩余保持到期待后续安排。

选择记忆等级即记录词卡；听读交卷自动完成主练习；写作达到最低字数并点完成草稿、口语完成全部流程后记录完成；复盘填写后点保存。词汇“再来”仍由 SM-2 安排下次到期，不代表已掌握。每日听读使用独立会话，不覆盖自由题库的作答。课程数据随完整备份导出。

首次升级从当天启用每日课程，旧版自由练习和学习记录保持原样；过去没有课程记录的日子不会伪造历史完成量。未来日期是预测，不能提前做完未来课程绕过每日容量。每天首次打开、跨日或窗口重新获得焦点时重新计算。关闭期间不运行后台程序。

**无需联网或 GitHub 后端。** 初次加载/下载网站后，排课、顺延和本机存档在浏览器执行；离线使用需先在设置启用离线包。GitHub Pages 可免费托管公开静态网站，Actions 仅用于构建和公共题库周更，不保存个人草稿、录音和进度。换设备请手动导出/导入备份，不会自动跨设备同步。

## ChatGPT 在线问答侧栏（v1.3）

右上角 ChatGPT 按钮打开/关闭侧栏。可引用学习页选中文本、整理问题、复制并打开官方 ChatGPT 小窗，在官方窗口登录 Plus、粘贴并提问；再将解答粘回本机问题本。默认在线，不需要本机助手或付费 API。提供弹窗/剪贴板失败时的普通链接和手动复制入口。

ChatGPT 的 CSP 不允许本网站直接内嵌官方网页，因此回答在独立小窗显示，不会自动回传侧栏；网站不读取登录信息，不会伪装为已连接 Plus。详细流程和限制见 [侧栏说明](docs/CHATGPT-SIDEBAR.md)。
